Executive summary

The Nexio Global website was reviewed against the OWASP Top 10 using static inspection of the React application, routing, forms, Firebase client integration, hosting configuration, and production dependencies.

No confirmed exploitable application vulnerabilities were identified in the reviewed source.

Four dependency advisories were identified during the initial audit. Targeted upgrades and package overrides were applied, and the production dependency audit now reports zero vulnerabilities.

Scope and methodology

  • React, TypeScript, Vite, Wouter routes, forms, and static content.
  • Firebase client initialization and Firebase Hosting configuration.
  • Dependency graph using npm audit --omit=dev.
  • OWASP Top 10 categories: injection, broken access control, cryptographic failures, insecure design, security misconfiguration, vulnerable components, identification/authentication failures, software/data integrity failures, logging/monitoring failures, and SSRF.

Recommendations

  1. Run a production header scan and enforce a restrictive Content Security Policy, HSTS, and clickjacking protection.
  2. Review Firebase Authentication, Firestore, Storage, IAM, and Hosting rules in the Firebase console.
  3. Add rate limiting and server-side validation if a backend or email submission endpoint is introduced.
  4. Schedule dependency audits in CI and review lockfile changes before release.
This report is a source and dependency review, not a penetration test or formal certification. Runtime infrastructure, third-party services, Firebase rules, and production DNS/CDN behavior were outside the repository-only assessment scope.
